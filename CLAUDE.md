# Claude Code

- Treat AGENTS.md as the canonical repository guidance.
- Treat a clear request to implement, fix, publish or continue a scoped task
  as authorization to complete the protected-branch delivery flow described
  in AGENTS.md. Do not request repeated approval for routine in-scope branch,
  commit, push, pull-request, green-check merge, deployment or verification
  steps unless the user asks for a checkpoint or local-only work.
- Ask before destructive, materially different or expanded actions outside
  the authorized scope, and whenever an AGENTS.md stop condition applies.
- Keep task-specific discoveries out of CLAUDE.md unless they are durable
  project conventions.

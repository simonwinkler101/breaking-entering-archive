# Claude Code

- Treat AGENTS.md as the canonical repository guidance.
- For broad, destructive, publishing or remote state-changing actions not
  already authorized, present the proposed scope and wait for explicit
  approval. Read-only inspection and routine in-scope local edits and builds
  do not require separate approval.
- Keep task-specific discoveries out of CLAUDE.md unless they are durable
  project conventions.
